# X Developer Platform

## Basic Package

### Overview

The X Developer Platform Basic Package is designed for **hobbyists and prototypes** who need enhanced API access beyond the free tier[^1]. This paid subscription provides rate-limited access to X's suite of v2 endpoints with significantly higher usage limits compared to the free plan.

### Pricing Structure

| **Plan Details**      | **Basic Package**                                  |
| --------------------- | -------------------------------------------------- |
| **Monthly Cost**      | $200/month                                         |
| **Annual Cost**       | $175/month ($2,100 total with annual subscription) |
| **Target Users**      | Hobbyists and prototypes                           |
| **Top-ups Available** | 2 top-ups allowed for additional usage             |

### Key Features & Capabilities

#### API Access

* **Full X API v2 access**: Complete suite of v2 endpoints[^2]
* **Limited v1.1 access**: Access to standard v1.1 endpoints with limitations[^2]
* **Ads API**: Full access to X Ads API for advertising campaigns[^2]
* **Login with X**: Integration capabilities for user authentication

#### Usage Limits

| **Usage Type**         | **Monthly Limit**      |
| ---------------------- | ---------------------- |
| **User-level posting** | 3,000 posts per month  |
| **App-level posting**  | 50,000 posts per month |
| **App-level reading**  | 15,000 reads per month |

#### Project & App Management

* **Project limit**: 1 Project allowed[^2]
* **App limit**: 2 Apps per Project[^2]
* **App IDs**: Access to 2 app IDs for managing different applications

### What's Included vs. Higher Tiers

#### Basic Package Limitations

* **No filtered stream API**: This feature is only available in Pro and Enterprise tiers[^2]
* **No full-archive search**: Limited to Pro and Enterprise access levels[^2]
* **No enterprise stream APIs**: Advanced streaming features require Enterprise tier[^2]

#### Comparison with Other Tiers

| **Feature**             | **Free** | **Basic** | **Pro**   | **Enterprise** |
| ----------------------- | -------- | --------- | --------- | -------------- |
| **Monthly Cost**        | Free     | $200      | $5,000    | Custom         |
| **Post Caps**           | 100      | 15,000    | 1,000,000 | 50M+           |
| **Apps per Project**    | 1        | 2         | 3         | 3+             |
| **Filtered Stream**     | ❌        | ❌         | ✅         | ✅              |
| **Full-Archive Search** | ❌        | ❌         | ✅         | ✅              |

### Use Cases & Target Applications

The Basic Package is ideal for:

* **Prototype development**: Testing and validating API integrations before scaling
* **Hobbyist projects**: Personal projects requiring moderate API usage
* **Small business applications**: Limited commercial use with moderate data needs
* **Educational purposes**: Learning and experimenting with X's API capabilities
* **Early-stage integrations**: Initial development phases of larger applications

### Getting Started

To access the Basic Package:

1. **Create a developer account**: Sign up at developer.x.com[^3]
2. **Complete onboarding**: Set up your first Project and App through the developer portal[^4]
3. **Purchase Basic access**: Upgrade from Free tier within the developer portal[^3]
4. **Receive credentials**: Get authentication keys and tokens for API access[^4]

### Important Considerations

#### Policy Compliance

* All uses must comply with X's Developer Agreement and Policy[^5]
* **Use case disclosure required**: You must provide a written description of your intended API usage[^5]
* **Scope limitations**: Basic plans are designed for hobbyists and prototyping, not large-scale commercial use[^5]

#### Technical Requirements

* **Secure credential storage**: Authentication keys and tokens must be stored securely[^4]
* **Rate limit management**: Respect API rate limits to avoid service interruptions
* **Top-up planning**: Consider the 2 available top-ups for exceeding monthly limits

### Summary

The X Developer Platform Basic Package offers a substantial upgrade from the free tier at $200/month, providing 150x more read capacity and 50x more posting capacity. It's positioned as the entry point for serious development work while maintaining affordability for smaller projects and prototypes[^1].
